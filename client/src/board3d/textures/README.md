# Board 3D textures

Source: ambientCG (https://ambientcg.com), licence CC0 (public domain), 1K-JPG packs.
- floor-*: MetalPlates013 (riveted plates, board floor)
- wall-*: MetalPlates011 (curved rusty wall)
- crate-*: MetalPlates014 (obstacle boxes)
Suffixes: color (albedo), normal (NormalGL, OpenGL convention), rough (roughness), metal (metalness).
Conversion: Pillow, JPG to RGB WebP 1024x1024, method=6, quality 82 (normal maps: 90).
Original archives are kept in assets/source/textures/ (moved out of context/import/, in the jarvis-jdr workspace, on 2026-10-15).
